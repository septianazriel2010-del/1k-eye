# 1K-Eye — Dunia dalam Jangkauan Mata

Simulator pemantauan dan intelijen berbasis web interaktif. Proyek ini menampilkan globe 3D fotorealistis yang dilengkapi data waktu nyata seperti penerbangan, kapal, satelit, gempa bumi, lalu lintas, dan kamera publik—serta kendali suara berbasis AI.

**1K-Eye — dunia dalam jangkauan mata.**

---

## ⚡ Fitur Utama

* **Tampilan Kokpit:** Ikuti pergerakan pesawat secara langsung dari sudut pandang kokpit di atas permukaan bumi 3D.
* **Pelacakan Global:** Pantau posisi pesawat, kapal, satelit (termasuk Stasiun Luar Angkasa Internasional/ISS), titik api aktif (NASA FIRMS), dan gempa bumi secara langsung.
* **Kamera Publik dan CCTV:** Integrasikan kamera pengawas publik dan siaran langsung ke dalam pemandangan kota 3D.
* **Navigasi dan Analisis:** Cari lokasi, ukur rute perjalanan darat, serta amati cuaca global (angin, awan, radar hujan, dan siklon tropis).
* **Mode Tampilan Sensor:** Ubah tampilan globe dengan filter seperti *CRT, penglihatan malam (NVG), termal (FLIR), Noir,* dan *Snow*.
* **TAMPILAN ▸ Gambar:** Buat area, garis, atau pin langsung pada globe, lalu tambahkan label dan warna. Klik titik-titik pada peta, kemudian klik dua kali atau tekan Enter untuk menyelesaikan bentuk. Backspace menghapus titik terakhir; Esc membatalkan bentuk, dan Esc sekali lagi keluar dari mode Gambar. Tombol **Hapus** menghilangkan semua tanda pada peta.

## 🚀 Cara Menjalankan Proyek Secara Lokal

Pastikan komputer kamu sudah terinstal **Node.js** (disarankan versi 24.x atau yang lebih baru).

1. Salin repositori ini atau buka folder proyek melalui terminal.
2. Pasang dependensi yang diperlukan:
   ```bash
   npm ci
   ```
3. Jalankan server pengembangan:
   ```bash
   npm run dev
   ```
4. Buka alamat lokal yang ditampilkan di terminal pada peramban.
