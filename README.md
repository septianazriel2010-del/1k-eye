# 🌐 God's Eye View (Custom Version)

Simulator satelit pengintai dan intelijen berbasis web interaktif. Proyek ini menampilkan globe 3D fotorealistik yang dilengkapi dengan data real-time seperti penerbangan, kapal, satelit, gempa bumi, lalu lintas, dan kamera publik—disertai kontrol suara berbasis AI.

Versi ini telah dirombak dan dikustomisasi secara mandiri oleh **Muhammad Septian Azriel Saputra**.

---

## ⚡ Fitur Utama

* **Tampilan Kokpit (Cockpit View):** Ikuti dan rasakan langsung sensasi berada di dalam pesawat yang sedang melintas secara real-time di atas permukaan bumi 3D.
* **Pelacakan Global:** Pantau posisi pesawat, kapal laut, satelit (termasuk stasiun luar angkasa ISS), titik api aktif (NASA FIRMS), hingga gempa bumi secara langsung.
* **Kamera Publik & Mesh CCTV:** Integrasi ribuan kamera pengawas publik dan live stream ke dalam pemandangan 3D kota.
* **Navigasi & Analisis:** Fitur pencarian lokasi, pengukuran rute perjalanan darat, hingga visualisasi cuaca global (angin, awan, radar hujan, dan siklon tropis).
* **Mode Tampilan Sensor (Reskin):** Ubah tampilan globe menggunakan berbagai filter sensor seperti *CRT, NVG (Night Vision), FLIR/Thermal, Noir,* hingga *Snow*.
