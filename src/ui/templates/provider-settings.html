Aktifkan fitur globe

Globe tetap dapat digunakan tanpa kunci API. Setiap kunci di bawah mengaktifkan sumber data nyata tambahan. Tempelkan kunci untuk menyimpannya ke konfigurasi lokal aplikasi; server akan dimulai ulang secara otomatis. Kunci sisi server tetap tersimpan di perangkat ini. Kunci Google Maps dan Cesium ion digunakan di peramban dan harus dibatasi untuk penyedia terkait. Kunci yang telah diatur di tempat lain hanya ditampilkan dan tidak akan diubah.
